# ربات موزیک تلگرام 🎵 (نسخه‌ی اشتراکی)

اسم آهنگ یا لینک یوتیوب می‌گیره و فایل صوتی (با کاور، اسم آهنگ و خواننده) می‌فرسته.
فقط کاربران و گروه‌هایی که **لایسنس** دارن می‌تونن ازش استفاده کنن.

## امکانات

**برای همه (PV و گروه)**
- نتایج صفحه‌بندی‌شده با دکمه‌ی شماره‌دار
- زیر هر آهنگ: ❤️ علاقه‌مندی، 🎼 آهنگ مشابه، 🔎 جستجوی دوباره
- کش هوشمند: آهنگی که یک‌بار آپلود شده، بعداً فوری ارسال می‌شه
- محافظ ضد اسپم (فاصله‌ی زمانی + یک درخواست همزمان برای هر نفر)

**چت خصوصی (PV)**
- منوی اصلی با دکمه: جستجو، پرطرفدارها، علاقه‌مندی‌ها، تاریخچه، پروفایل، تنظیمات
- انتخاب کیفیت صدا (۱۲۸ / ۱۹۲ / ۳۲۰)
- فعال‌سازی لایسنس با دکمه یا `/redeem`

**گروه**
- `/play اسم آهنگ` و جستجوی دوباره با ریپلای
- `/panel` پنل مدیریت (فقط ادمین‌ها): دسترسی همه/فقط ادمین، فاصله‌ی درخواست، دکمه‌های زیر آهنگ، پاکسازی خودکار
- آمار گروه و پرطرفدارهای گروه، فعال‌ترین اعضا
- لایسنس گروه جداست: ادمین گروه `/redeem کد` می‌زنه

**مالک ربات**
- `/admin` پنل مالک، `/genkey`، `/grant`، `/revoke`، `/ban`، `/unban`، `/keys`، `/stats`، `/broadcast`
- مدیریت یوتیوب: `/cookies` (ثبت کوکی مستقیم تو تلگرام)، `/ytcheck` (تست سلامت)، `/updateyt` (آپدیت yt-dlp)
- اگه یوتیوب بات‌چک بندازه، ربات خودش به مالک پیام می‌ده
- یادآوری خودکار به کاربر/گروه یک روز قبل از تموم شدن اشتراک

## نصب (ساده)
1. پایتون ۳.۱۰+ و **ffmpeg** نصب باشه (ویندوز: `winget install ffmpeg`).
2. وابستگی‌ها (حتماً دوباره بزن، چون چند تا چیز جدید اضافه شده):
   ```
   pip install -r requirements.txt
   ```
3. توکن رو از `@BotFather` بگیر.
4. **آیدی عددی خودت** رو از ربات `@userinfobot` بگیر (این می‌شه `OWNER_IDS`).
5. فایل `.env.example` رو به `.env` تغییر اسم بده و پرش کن:
   - `BOT_TOKEN` توکن ربات
   - `OWNER_IDS` آیدی عددی خودت (چند نفر: با کاما جدا کن)
   - `SUPPORT_USERNAME` یوزرنیم تلگرام خودت یا پشتیبانی، بدون @ (برای دکمه‌ی خرید)
   - `PLANS_TEXT` متن تعرفه‌ها (برای رفتن به خط بعد `\n` بنویس)
   - `TRIAL_DAYS` اگه بخوای کاربر جدید چند روز رایگان داشته باشه (پیش‌فرض ۰)
6. اجرا:
   ```
   python bot.py
   ```
7. تو `@BotFather`: `/setprivacy` → ربات → **Disable**. بعد ربات رو تو گروه ادمین کن.

## فروش لایسنس (قدم به قدم)
1. تو چت خصوصی با ربات (با اکانت مالک) بنویس:
   ```
   /genkey 30
   ```
   یه کد ۳۰ روزه می‌ده مثل `MB-1A2B-3C4D-5E6F-7A8B`.
2. چند تا یکجا: `/genkey 30 10` (۱۰ تا کد ۳۰ روزه).
3. فقط برای گروه یا فقط برای شخص: `/genkey 30 5 group` یا `/genkey 30 5 user`.
4. کد رو به مشتری بفروش. مشتری:
   - **شخصی:** تو PV ربات دکمه‌ی «🔑 فعال‌سازی لایسنس» یا `/redeem کد`
   - **گروه:** ادمین گروه تو گروه `/redeem کد` (پیام کد خودکار پاک می‌شه)
5. هر کد فقط یک بار قابل استفاده‌ست. تمدید: کد جدید رو بزنن، به اشتراک فعلی اضافه می‌شه.
6. اشتراک مستقیم بدون کد: `/grant آیدی روز` (آیدی گروه با منفی شروع می‌شه).
7. حذف اشتراک: `/revoke آیدی`. مسدود کردن: `/ban آیدی`.

## اجرای دائمی روی سرور
خارج از ایران، با tmux (ساده‌ترین راه):
```
tmux new -s musicbot
python bot.py
# خروج بدون خاموش شدن: Ctrl+B بعد D
```

## 🤖 درست کردن بات‌چک یوتیوب (Sign in to confirm you're not a bot)

این خطا یعنی یوتیوب به IP سرور یا کوکی‌ها اعتماد نداره. به ترتیب این کارها رو بکن:

1. **اول yt-dlp رو آپدیت کن** (نصف مشکلات همینه — یوتیوب هر چند هفته چیزو عوض می‌کنه):
   ```
   pip install -U yt-dlp
   ```
   یا تو خود ربات (با اکانت مالک): `/updateyt` — بعدش ربات رو ری‌استارت کن.
2. **تست سلامت بگیر:** تو PV ربات `/ytcheck` بزن. دقیق می‌گه چی کمه و تست جستجو/دانلود واقعی هم انجام می‌ده.
3. **JS runtime نصب کن (مهم):** نسخه‌های جدید yt-dlp برای حل چالش‌های یوتیوب به Deno (یا Node) نیاز دارن:
   ```
   curl -fsSL https://deno.land/install.sh | sh
   ```
   ویندوز: `irm https://deno.land/install.ps1 | iex` — بعدش PowerShell رو ببند و دوباره باز کن.
4. **کوکی ثبت کن (راحت‌ترین راه):**
   - تو مرورگر (ترجیحاً یه اکانت کم‌مصرف، **نه اکانت اصلیت**) وارد youtube.com شو.
   - با افزونه‌ی «Get cookies.txt LOCALLY» فایل cookies.txt رو خروجی بگیر.
   - فایل رو تو PV ربات بفرست و روی همون فایل ریپلای کن: `/cookies`
   - تموم! فایل کنار ربات ذخیره می‌شه و بعد از ری‌استارت هم خودکار استفاده می‌شه. دیگه لازم نیست `.env` رو دستی ویرایش کنی.
5. **(اختیاری ولی مؤثرترین راه) PO Token provider نصب کن** — ربات خودش تشخیص می‌ده و استفاده می‌کنه:
   ```
   pip install bgutil-ytdlp-pot-provider
   ```
   به‌علاوه سرور provider (با Docker یا Node) طبق راهنمای ریپوی خودش.
6. **اگه IP سرور کاملاً فلگ شده**، تو `.env` پروکسی بذار:
   ```
   YTDLP_PROXY=socks5://user:pass@host:port
   ```

**نکته‌ها:**
- کوکی رو از اکانت اصلی گوگلت نگیر؛ اکانت کم‌مصرف/جدید بهتره.
- اگه کوکی هر چند روز یه‌بار می‌میره، مشکل از کوکی نیست؛ IP سرور فلگ شده → پروکسی یا PO Token provider.
- وقتی بات‌چک فعال می‌شه، ربات خودش به مالک پیام می‌ده؛ دیگه لازم نیست لاگ‌ها رو دنبال کنی.
- دکمه‌ی «🩺 وضعیت یوتیوب» هم تو پنل مالک `/admin` اضافه شده.
